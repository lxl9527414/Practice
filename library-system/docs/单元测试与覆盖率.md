# 云阁图书借阅系统 · 单元测试与覆盖率

> 更新时间：2026-10-13
> 测试框架：JUnit 5 + Mockito + AssertJ（`spring-boot-starter-test`）
> 覆盖率工具：JaCoCo 0.8.12（已集成在 `backend/pom.xml`）

## 1. 运行方式

```bash
cd backend
mvn test
```

- 测试报告：`backend/target/surefire-reports/`
- 覆盖率报告：`backend/target/site/jacoco/index.html`（浏览器打开）
- 覆盖率明细：`backend/target/site/jacoco/jacoco.csv`

单元测试全部基于 Mockito 纯内存运行：**不依赖 MySQL、Redis 和网络**，可在任意机器或 CI 上直接执行。

### 3.4 如何理解这组数字

总体 48.6% 的覆盖率是**有意选择的结果**：

- 已覆盖：借阅、预约、规则、库存、审计、登录态等**承载业务规则的核心逻辑**，这些类覆盖率在 70% ~ 100%
- 未覆盖：Controller、Entity、DTO、VO、Config、拦截器等**以框架委派为主、几乎无分支逻辑的代码**，它们把总体数值拉低，但不影响核心逻辑的验证强度

如果为了"好看"去给实体类和配置类补测试，覆盖率能快速升到 70%+，但对质量没有实际帮助，因此这里保留真实口径。
